# Feature: multi-agent-symlink-support

## Overview
Extend the contextual development tools to support multiple AI agent configurations and implement symlink-based command management for local development. This feature will allow users install with different AI agents (beyond just Cursor).

## Requirements
- Create top level `./commands` folder
- Create symlink from `.cursor/commands` to `./commands` for local development
- `install.sh` will copy files from `./commands` folder to the appropriate agent folder in the PROJECT_ROOT by specifying the agent name with the `--agent` flag
